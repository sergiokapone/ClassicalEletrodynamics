Розділ 3 Вільне електромагнітне поле

В цьому розділі розглянуто питання, що стосуються вільних електромагнітних полів у вакуумі, тобто за відсутності зарядів та струмів. Основним методом аналізу є розклад поля за допомогою перетворення Фур’є, що дозволяє перейти від опису поля як функції часу до його спектральних характеристик. Такий підхід природно веде до поняття плоских хвиль та монохроматичних полів, для яких особливо зручним є комплексний формалізм при обчисленні енергетичних співвідношень. Розділ завершується розкладом вільного поля на незалежні моди, які формально описуються як гармонічні осцилятори, що є відправною точкою для квантової теорії електромагнітного поля.

3.1 Спектральний розклад і плоскі хвилі

Зведення до додатних частот

Нехай \(\phi (t)\) — будь-яка функція, пов’язана з електромагнітним полем (наприклад, компонента електричного поля), для якої існує образ Фур’є:

\(\seteqnumber{0}{3.}{0}\)

\begin{equation} \tilde {\phi }(\omega ) = \frac {1}{\sqrt {2\pi }} \int \limits _{-\infty }^{\infty } dt \, e^{i\omega t} \phi (t) \label {eq:fourier_transform} \end{equation}

Обернене перетворення дозволяє обчислити \(\phi (t)\) по функції \(\tilde {\phi }(\omega )\):

\(\seteqnumber{0}{3.}{1}\)

\begin{equation} \phi (t) = \frac {1}{\sqrt {2\pi }} \int \limits _{-\infty }^{\infty } d\omega \, e^{-i\omega t} \tilde {\phi }(\omega ) \label {eq:inverse_fourier_transform} \end{equation}

Для функцій \(f(t)\), \(g(t)\) та їх образів Фур’є \(\tilde {f}(\omega )\), \(\tilde {g}(\omega )\) виконується рівність Парсеваля:

\(\seteqnumber{0}{3.}{2}\)

\begin{equation} \label {eq:Parseval} \int \limits _{-\infty }^{\infty } f(t)g^{*}(t)dt = \int \limits _{-\infty }^{\infty } \tilde {f}(\omega )\tilde {g}^{*}(\omega )d\omega \end{equation}

Практично будь-який реальний сигнал можна подати у вигляді суперпозиції монохроматичних сигналів. За допомогою технічних пристроїв можна виділяти, підсилювати чи послабляти певні ділянки спектра сигналу, що відповідають певній області частот. При цьому формальний запис гармонічних сигналів, пропорційних \(\sim e^{i\omega t}\) та \(\sim e^{-i\omega t}\), відповідає однаковій частоті \(\omega > 0\). Тому перепишемо усі співвідношення через додатні значення \(\omega \), враховуючи, що фізичні напруженості полів описуються дійсними функціями.

Якщо \(\phi (t)\) — дійсна функція, то:

\(\seteqnumber{0}{3.}{3}\)

\begin{equation} \label {eq:conjugate_frequency} \tilde {\phi }^{*}(\omega ) = \frac {1}{\sqrt {2\pi }} \int \limits _{-\infty }^{\infty } dt \, e^{-i\omega t} \phi (t) = \tilde {\phi }(-\omega ) \end{equation}

Завдяки цьому формулу (3.2) можна переписати так:

\(\seteqnumber{0}{3.}{4}\)

\begin{multline*} \phi (t) = \frac {1}{\sqrt {2\pi }} \left ( \int \limits _{0}^{\infty } d\omega \, e^{-i\omega t} \tilde {\phi }(\omega ) + \int \limits _{-\infty }^{0} d\omega \, e^{-i\omega t} \tilde {\phi }(\omega ) \right ) = \\ = \frac {1}{\sqrt {2\pi }} \int \limits _{0}^{\infty } d\omega \left ( \hat {\phi }(\omega ) e^{-i\omega t} + \hat {\phi }^{*}(\omega ) e^{i\omega t} \right ) \end{multline*}

В цю формулу входять значення \(\tilde {\phi }(\omega ) \) лише з додатними частотами, які можна задавати незалежно на відміну від \(\phi (-\omega ) \) при \(\omega > 0 \), які пов’язані з \(\phi (\omega ) \) формулою (3.4). Формулу зведення до додатних частот можна переписати так:

\(\seteqnumber{0}{3.}{4}\)

\begin{equation} \phi (t) = \sqrt {\frac {2}{\pi }} \Re \int \limits _{0}^{\infty } d\omega e^{-i\omega t} \tilde {\phi }(\omega ) \label {eq:positive_frequencies} \end{equation}

З урахуванням (3.4) для дійсної функції \(f(t) \) можна записати:

\(\seteqnumber{0}{3.}{5}\)

\begin{equation*} \int \limits _{-\infty }^{\infty } f^2(t) dt = \int \limits _{-\infty }^{\infty } |\tilde {f}(\omega )|^2 d\omega = 2\int \limits _{0}^{\infty } |\tilde {f}(\omega )|^2 d\omega \end{equation*}

Енергетичні співвідношення

Повна енергія, що проходить через поверхню, що оточує об’єм \(\Omega \) за весь час випромінювання:

\(\seteqnumber{0}{3.}{5}\)

\begin{multline*} \mathcal {E} = \int \limits _{-\infty }^{\infty } \oint \limits _{\partial \Omega } \vect {\Pi } \cdot d\vect {S}\, dt = \frac {c}{4\pi } \oint \limits _{\partial \Omega } \int \limits _{-\infty }^{\infty } \left [ \Efield \times \Bfield \right ] \cdot dt\, d\vect {S} = \\ = \frac {c}{4\pi } \oint \limits _{\partial \Omega } d\vect {S} \cdot \int \limits _{-\infty }^{\infty } \left [ \tilde {\Efield }(\omega ) \times \tilde {\Bfield }^{*}(\omega ) \right ] d\omega \end{multline*} де \(\tilde {\Efield }(\omega ), \tilde {\Bfield }(\omega ) \) — спектральні характеристики дійсних полів \(\Efield (t), \Bfield (t) \).

Аналогічно (3.4):

\(\seteqnumber{0}{3.}{5}\)

\begin{equation*} \tilde {\Efield }(-\omega ) = \tilde {\Efield }^{*}(\omega ), \quad \tilde {\Bfield }(-\omega ) = \tilde {\Bfield }^{*}(\omega ). \end{equation*}

Тоді, розбиваючи інтеграл по \(d\omega \) на два додатки:

\(\seteqnumber{0}{3.}{5}\)

\begin{equation*} \int \limits _{-\infty }^{\infty } d\omega \left \{ \ldots \right \} = \int \limits _{0}^{\infty } d\omega \left \{ \ldots \right \} + \int \limits _{-\infty }^{0} d\omega \left \{ \ldots \right \}, \end{equation*}

кожне з яких є комплексним спряженням іншого, аналогічно (3.5), маємо:

\(\seteqnumber{0}{3.}{5}\)

\begin{equation} \mathcal {E} = \frac {c}{2\pi } \oint \limits _{\partial \Omega } d\vect {S} \cdot \Re \int \limits _{0}^{\infty } \left [\tilde {\Efield }(\omega ) \times \tilde {\Bfield }^{*}(\omega ) \right ] d\omega \label {eq:energy_positive_frequencies} \end{equation}

де фігурують вже тільки додатні частоти.

Якщо експериментальна техніка дає змогу виділяти внесок окремих інтервалів частот, доцільно ввести спектральну густину енергії випромінювання.

\(\seteqnumber{0}{3.}{6}\)

\begin{equation*} \frac {d\mathcal {E}}{d\omega } = \frac {c}{2\pi } \oint \limits _{\partial \Omega } d\vect {S} \cdot \Re \left [ \tilde {\Efield }(\omega ) \times \tilde {\Bfield }^{*}(\omega )\right ], \quad \omega > 0 \end{equation*}

Тоді з (3.6):

\(\seteqnumber{0}{3.}{6}\)

\begin{equation*} \mathcal {E} = \int \limits _0^{\infty } \frac {d\mathcal {E}}{d\omega } d\omega \end{equation*}

Комплексний формалізм та енергетичні співвідношення для монохроматичних полів

В попередніх співвідношеннях комплексні величини \(\tilde {\Efield }\), \(\tilde {\Bfield }\) — це образи Фур’є відповідних дійсних полів. Доцільно розглядати також комплексні поля, які є розв’язками рівнянь Максвелла. Завдяки лінійності рівнянь, дійсні та уявні частини комплексних розв’язків також є розв’язками, але розрахунки з комплексними величинами часто є більш зручними. При розгляді ж спостережних величин або нелінійних (наприклад, енергетичних) співвідношень слід повернутися до дійсних частин розв’язків, які мають фізичний зміст.

Проілюструємо це на прикладі комплексних монохроматичних полів, тобто таких, що залежать від часу як \(e^{-i\omega t}\), \(\omega \neq 0\). Нехай електричне та магнітне поля є монохроматичними, тобто

\(\seteqnumber{0}{3.}{6}\)

\begin{equation*} \Efield _{\text {real}}(t, \vect {r}) = \Efield '_0(\vect {r}) \cos (\omega t + \alpha ), \quad \Bfield _{\text {real}}(t, \vect {r}) = \Bfield '_0(\vect {r}) \cos (\omega t + \alpha ) \label {eq:real_fields} \end{equation*}

Ми зіставляємо їм комплексні поля

\(\seteqnumber{0}{3.}{6}\)

\begin{equation*} \Efield (t, \vect {r}) = \Efield _0(\vect {r}) e^{-i\alpha } e^{-i\omega t} \quad \Bfield (t, \vect {r}) = \Bfield _0(\vect {r}) e^{-i\alpha } e^{-i\omega t}, \label {eq:complex_fields} \end{equation*}

\(\seteqnumber{0}{3.}{6}\)

\begin{equation*} \Efield _0(\vect {r}) = \Efield '_0(\vect {r}) e^{-i\alpha }, \quad \Bfield _0(\vect {r}) = \Bfield '_0(\vect {r}) e^{-i\alpha }, \end{equation*}

дійсні частини яких збігаються з полями \(\Efield _{\text {real}}\), \(\Bfield _{\text {real}}\).

Вектор Пойнтінга густини потоку енергії виражаємо, як звичайно, через дійсні частини полів1:

\(\seteqnumber{0}{3.}{6}\)

\begin{multline*} \vect {\Pi } = \frac {c}{4\pi } \left [ \frac {\Efield + \Efield ^{*}}{2} \times \frac {\Bfield + \Bfield ^{*}}{2} \right ] = \\ = \frac {c}{8\pi } \left ( \frac {[\Efield \times \Bfield ^{*}]}2 + \frac {[\Efield ^{*} \times \Bfield ]}2 \right ) + \frac {c}{16\pi } \left ( [\Efield \times \Bfield ] + [\Efield ^{*} \times \Bfield ^{*}] \right ). \end{multline*}

Складові другого доданку осцилюють як \(e^{\pm 2i\omega t}\); їх середнє за часом дорівнює нулю. Усереднюючи за часом, маємо:

\(\seteqnumber{0}{3.}{6}\)

\begin{equation} \langle \vect {\Pi } \rangle _t = \frac {c}{8\pi } \Re \left [\Efield \times \Bfield ^{*}\right ] \label {eq:time_averaged_poynting} \end{equation}

де символ \(\langle F(t) \rangle _t = \lim \limits _{T \to \infty } \left \{ \frac {1}{T} \int \limits _{-T}^{T} F(t) dt \right \}\) означає усереднення за часом. Фактично, (3.7) — це вираз для середньої за часом густини потоку енергії через амплітуди монохроматичних електричного та магнітного полів.

Аналогічним чином легко отримати середнє за часом значення густини енергії електромагнітного поля:

\(\seteqnumber{0}{3.}{7}\)

\begin{equation} \langle W \rangle _t = \frac {\lvert \Efield \rvert ^2 + \lvert \Bfield \rvert ^2}{16\pi } \label {eq:energy_density_average} \end{equation}

Зауважимо, що формули (3.7), (3.8) не змінять свого вигляду у випадку суперпозиції монохроматичних хвиль з різними частотами. Це очевидно, коли врахувати, що \(\langle e^{i(\omega _1 - \omega _2)t} \rangle _t = 0\), \(\omega _1 \neq \omega _2\).

Розглянемо монохроматичні плоскі хвилі:

\(\seteqnumber{0}{3.}{8}\)

\begin{equation*} \Efield = \Efield _0 e^{i(\vect {k} \cdot \vect {r} - \omega t)}, \quad \Bfield = \Bfield _0 e^{i(\vect {k} \cdot \vect {r} - \omega t)} \label {eq:monochromatic_waves} \end{equation*}

Підставимо це в рівняння Максвелла. За відсутності зарядів та струмів, маємо:

\(\seteqnumber{0}{3.}{8}\)

\begin{align*} \Rot \Efield & = i[\vect {k} \times \Efield ] = \frac {i\omega }{c} \Bfield , \\ \Rot \Bfield = i[\vect {k} \times \Bfield ] = \frac {i\omega }{c} \Efield , \end{align*} а також умову поперечності:

\(\seteqnumber{0}{3.}{8}\)

\begin{align*} \Div \Efield & = i(\vect {k} \cdot \Efield ) = 0, \\ \Div \Bfield & = i(\vect {k} \cdot \Bfield ) = 0 \end{align*}

З першого рівняння:

\(\seteqnumber{0}{3.}{8}\)

\begin{equation*} [\vect {k} \times [\vect {k} \times \Efield ]] = \vect {k}(\vect {k} \cdot \Efield ) - \Efield k^2 = \frac {\omega }{c}[\vect {k} \times \Bfield ] = -\frac {\omega ^2}{c^2} \Efield \end{equation*}

Завдяки умові поперечності маємо:

\(\seteqnumber{0}{3.}{8}\)

\begin{equation*} \vect {k}^2 = \frac {\omega ^2}{c^2} \label {eq:dispersion_relation} \end{equation*}

— зв’язок між хвильовим вектором та частотою, який називають дисперсійним рівнянням.

Таким чином:

\(\seteqnumber{0}{3.}{8}\)

\begin{equation*} \Bfield = [\vect {n} \times \Efield ], \quad (\Bfield \cdot \vect {n}) = (\Efield \cdot \vect {n}) = 0, \quad (\Efield \cdot \Bfield ) = 0 \label {eq:wave_properties} \end{equation*}

де \(\vect {n} = \vect {k} / |\vect {k}|\) визначає напрям поширення хвилі.

1 Дійсна частина комплексного числа \(z\) є \(\Re {(z)} = \frac {z + z^*}2\) (зірочка означає комплексне спряження).

Плоскі хвилі у загальному випадку

Монохроматичні плоскі хвилі є частковим видом плоских хвиль, що визначаються, як розв’язки рівнянь електродинаміки, параметри яких не змінюються при переміщеннях вздовж деякої площини — фронту хвилі, нормаль до якої \(\vect {n}\) не змінюється з часом. Інакше, просторова залежність цих розв’язків зводиться до залежності від деякої змінної \(\zeta = (\vect {n} \cdot \vect {r})\), \(\vect {n}^2 = 1\). Тоді \(\Efield = \Efield (\zeta , t)\), \(\Bfield = \Bfield (\zeta , t)\).

Підставляючи в рівняння Максвелла, маємо:

\(\seteqnumber{0}{3.}{8}\)

\begin{equation} \Rot \Efield = \vect {n} \times \frac {\partial \Efield }{\partial \zeta } = -\frac {1}{c} \frac {\partial \Bfield }{\partial t} \label {eq:maxwell_rotE} \end{equation}

\(\seteqnumber{0}{3.}{9}\)

\begin{equation} \Rot \Bfield = \vect {n} \times \frac {\partial \Bfield }{\partial \zeta } = \frac {1}{c} \frac {\partial \Efield }{\partial t} \label {eq:maxwell_rotB} \end{equation}

\(\seteqnumber{0}{3.}{10}\)

\begin{equation} \Div \Efield = \vect {n} \cdot \frac {\partial \Efield }{\partial \zeta } = 0, \quad \Div \Bfield = \vect {n} \cdot \frac {\partial \Bfield }{\partial \zeta } = 0 \label {eq:maxwell_div} \end{equation}

Обчислимо \(\Rot (\eqref {eq:maxwell_rotE})\):

\(\seteqnumber{0}{3.}{11}\)

\begin{equation*} \Rot (\Rot \Efield ) = \grad (\Div \Efield ) - \Laplasian \Efield = -\Laplasian \Efield \end{equation*}

З (3.9):

\(\seteqnumber{0}{3.}{11}\)

\begin{equation*} -\Rot \left ( \frac {1}{c} \frac {\partial \Bfield }{\partial t} \right ) = -\frac {1}{c^2} \frac {\partial ^2 \Efield }{\partial t^2}, \end{equation*}

тобто:

\(\seteqnumber{0}{3.}{11}\)

\begin{equation} \Laplasian \Efield = \frac {1}{c^2} \frac {\partial ^2 \Efield }{\partial t^2} \label {eq:wave_equation_E} \end{equation}

Підставляючи сюди вираз для плоских хвиль \(\Efield = \Efield (\zeta , t)\):

\(\seteqnumber{0}{3.}{12}\)

\begin{equation*} \frac {\partial ^2 \Efield }{\partial \zeta ^2} = \frac {1}{c^2} \frac {\partial ^2 \Efield }{\partial t^2} \end{equation*}

Заміна \(U =\zeta - ct\), \(V =\zeta + ct\) приводить до рівняння:

\(\seteqnumber{0}{3.}{12}\)

\begin{equation*} \frac {\partial ^2 \Efield }{\partial U \partial V} = 0, \end{equation*}

загальним розв’язком якого є \(\Efield = \vect {F}_1(U) + \vect {F}_2(V)\), де \(\vect {F}_1\) та \(\vect {F}_2\) — довільні вектор-функції одної змінної. Розв’язок є суперпозицією двох хвиль, що рухаються в протилежних напрямках.

Якщо \(\Efield = \Efield (\zeta , t)\), \(\Bfield = \Bfield (\zeta , t)\), з рівняння (3.9) маємо:

\(\seteqnumber{0}{3.}{12}\)

\begin{equation*} \vect {n} \times \frac {\partial \Efield }{\partial \zeta } = \frac {\partial \Bfield }{\partial \zeta } \end{equation*}

Якщо перед фронтом \(\Efield = \Bfield = 0\), звідси \(\Bfield = [\vect {n} \times \Efield ]\), як і в плоскій монохроматичній хвилі.

Аналогічно, з (3.10):

\(\seteqnumber{0}{3.}{12}\)

\begin{equation*} \Efield = [\Bfield \times \vect {n}], \quad (\Bfield \cdot \vect {n}) = (\Efield \cdot \vect {n}) = 0 \end{equation*}

3.2 Випадкові поля випромінювання

Основні характеристики випадкових полів

Монохроматичні хвилі являють дуже ідеалізований випадок хвильового поля. Найчастіше в природі ми зустрічаємось із суперпозиціями полів, створених випадковими реалізаціями випромінювачів (атомів, молекул тощо). Фізичний опис процесу вимірювання цих величин має справу з обчисленням середніх значень за часом або середніх за деякими просторовими масштабами. Розмір області усереднення в кожному фізичному процесі визначається окремо. Але за певних широких умов цей спосіб усереднення еквівалентний статистичному усередненню, коли замість одного поля розглядають велику кількість реалізацій — ансамбль хвильових полів — і обчислення проводять за допомогою усереднень за ансамблем2. Цей підхід добре відомий зі статистичної механіки. Його можна застосовувати також при обчисленні електричних та магнітних величин, що вимірюють за допомогою макроскопічних приладів.

Розглянемо спочатку електромагнітне поле, для простоти не звертаючи уваги на ефекти, пов’язані з поляризацією. Тоді це поле можна описувати за допомогою скалярної функції \(\phi (t)\), що представляє, наприклад, одну з компонент електричного чи магнітного поля, маючи на увазі, що інші компоненти можна розглянути аналогічно. Будемо користуватися комплексним формалізмом (див. 3.1); нагадаємо, що при цьому в виразі для густини енергії (3.8) фігурують квадрати модулів полів.

Математичний опис стохастичних полів використовує поняття випадкового процесу. Нагадаємо, що випадковий процес \(\phi (t)\) заданий, якщо для будь-якого набору \(\{t_1, t_2, \dots , t_N\}\) заданий спільний розподіл ймовірностей

\(\seteqnumber{0}{3.}{12}\)

\begin{equation*} w(\phi _1, \phi _2, \dots , \phi _N; t_1, t_2, \dots , t_N) \end{equation*}

величин \(\phi (t_1), \phi (t_2), \dots , \phi (t_N)\). Процес називають стаціонарним, якщо спільний розподіл

\(\seteqnumber{0}{3.}{12}\)

\begin{equation*} w(\phi _1, \phi _2, \dots , \phi _N; t_1 + \tau , t_2 + \tau , \dots , t_N + \tau ) \end{equation*}

величин \(\phi (t_1 + \tau ), \phi (t_2 + \tau ), \dots , \phi (t_N + \tau )\) не залежить від часового зсуву \(\tau \). Знаючи розподіл ймовірностей значень поля для будь-яких часів \(\{t_1, t_2, \dots , t_N\}\), можна обчислювати середні від лінійних, квадратичних за полем величин тощо. Ці середні в цьому підрозділі ми позначаємо знаком \(\langle \dots \rangle \). З фізичного погляду процедуру усереднення можна інтерпретувати, як обчислення середньоарифметичних величин за даними великої кількості експериментів-реалізацій. Така інтерпретація часто є цілком достатньою для проведення обчислень.

Для стаціонарного процесу середнє \(\langle \phi (t) \rangle \equiv \langle \phi \rangle \). При розгляді випадкових полів випромінювання вважають \(\langle \phi \rangle = 0\).

Важливою характеристикою випадкового процесу є кореляційна (автокореляційна) функція4:

\(\seteqnumber{0}{3.}{12}\)

\begin{equation} A(\tau ) = \langle \phi ^{*}(t) \phi (t + \tau ) \rangle \label {eq:autocorrelation} \end{equation}

Для стаціонарного процесу:

\(\seteqnumber{0}{3.}{13}\)

\begin{equation*} A(-\tau ) = \langle \phi ^{*}(t) \phi (t - \tau ) \rangle = \langle \phi ^{*}(t + \tau ) \phi (t) \rangle = A^{*}(\tau ) \end{equation*}

не залежить від \(t\).

Розглянемо формально перетворення Фур’є випадкової функції:

\(\seteqnumber{0}{3.}{13}\)

\begin{equation*} \tilde \phi (\omega ) = \frac {1}{\sqrt {2\pi }} \int \limits _{-\infty }^{\infty } dt \, e^{i\omega t} \phi (t) \end{equation*}

Щоб надати змісту цьому невласному інтегралу в разі стаціонарного випадкового процесу, для кожної реалізації можна розглядати вираз:

\(\seteqnumber{0}{3.}{13}\)

\begin{equation*} \tilde \phi _T(\omega ) = \frac {1}{\sqrt {2\pi }} \int \limits _{-T}^{T} dt \, e^{i\omega t} \phi (t) \end{equation*}

Обчислимо для стаціонарного процесу:

\(\seteqnumber{0}{3.}{13}\)

\begin{multline*} \langle \tilde \phi (\omega ) \tilde \phi ^{*}(\omega ') \rangle = \frac {1}{2\pi } \int \limits _{-\infty }^{\infty } dt' \, e^{i(\omega - \omega ')t'} \int \limits _{-\infty }^{\infty } dt \, e^{i\omega (t - t')} \langle \phi ^{*}(t') \phi (t) \rangle =\\ = \frac {1}{2\pi } \int \limits _{-\infty }^{\infty } dt' \, e^{i(\omega - \omega ')t'} \int \limits _{-\infty }^{\infty } dt \, e^{i\omega (t - t')} A(t - t') \end{multline*}

Користуючись відомим співвідношенням:

\(\seteqnumber{0}{3.}{13}\)

\begin{equation*} \lim _{T \to \infty } \int \limits _{-T}^{T} dt' \, e^{i(\omega - \omega ')t'} = 2\pi \delta (\omega - \omega ') \end{equation*}

дістанемо:

\(\seteqnumber{0}{3.}{13}\)

\begin{equation} \langle \tilde \phi (\omega ) \tilde \phi ^{*}(\omega ') \rangle = \delta (\omega - \omega ') S(\omega ) \label {eq:spectral_density} \end{equation}

де

\(\seteqnumber{0}{3.}{14}\)

\begin{equation*} S(\omega ) = \int \limits _{-\infty }^{\infty } d\tau \, e^{i\omega \tau } A(\tau ) \end{equation*}

називають спектральною густиною (чи спектром потужності) випадкового процесу. Очевидно

\(\seteqnumber{0}{3.}{14}\)

\begin{equation*} A(\tau ) = \frac {1}{2\pi } \int \limits _{-\infty }^{\infty } d\omega \, e^{-i\omega \tau } S(\omega ). \end{equation*}

2 Стаціонарні процеси, для яких часові середні збігаються з середніми за ансамблем, називають ергодичними. Дослідник має вирішити, наскільки модель ергодичного процесу адекватна конкретній фізичній ситуації.

4 У деяких підручниках у визначенні (3.13) від правої частини віднімають \(\langle \phi (t) \rangle \langle \phi ^{*}(t + \tau ) \rangle \).

Когерентність

Для суперпозиції двох хвильових полів \(\phi _1\) та \(\phi _2\) сумарна інтенсивність визначається квадратичною величиною:

\(\seteqnumber{0}{3.}{14}\)

\begin{equation*} I = |\phi _1 + \phi _2|^2 = |\phi _1|^2 + |\phi _2|^2 + 2 \Re (\phi _1 \phi _2^{*}), \end{equation*}

а для середніх:

\(\seteqnumber{0}{3.}{14}\)

\begin{equation} \langle I \rangle = \langle I_1 \rangle + \langle I_2 \rangle + 2 \Re \langle \phi _1 \phi _2^{*} \rangle \label {eq:intensity} \end{equation}

де \(I_i = \langle |\phi _i|^2 \rangle \) — інтенсивності окремих полів, \(i = 1, 2 \).

Розглянемо дві протилежних ситуації — повної когерентності та некогерентності двох полів.

  • 1. Суперпозиція двох полів, що пов’язані умовою:

    \(\seteqnumber{0}{3.}{15}\)

    \begin{equation*} \phi _2 = \alpha \phi _1 = |\alpha | \phi _1 e^{i\delta }, \quad \text {де } \delta = \text {Arg}(\alpha ). \end{equation*}

    В цьому випадку:

    \(\seteqnumber{0}{3.}{15}\)

    \begin{equation*} \langle \phi _1 \phi _2^{*} \rangle = \phi _1 \phi _2^{*} = 2\sqrt {I_1 I_2} \cos \delta \end{equation*}

    Умова зв’язку між \(\phi _1\) та \(\phi _2\) є випадком ідеальної корельованості, або когерентності цих полів. Такі поля можна отримати при розділенні світлового пучка в інтерферометрі, або, наприклад, у разі двох монохроматичних радіоджерел, що мають однакову частоту.

  • 2. Суперпозиція двох незалежних полів, генерованих двома незалежними випадковими випромінювачами:

    \(\seteqnumber{0}{3.}{15}\)

    \begin{equation*} \langle \phi _1 \phi _2^{*} \rangle = \langle \phi _1 \rangle \langle \phi _2^{*} \rangle \end{equation*}

    Як правило, для хвильового випадкового поля його середнє значення є нуль:

    \(\seteqnumber{0}{3.}{15}\)

    \begin{equation*} \langle \phi _1 \rangle = \langle \phi _2 \rangle = 0, \end{equation*}

    тому \(\langle \phi _1 \phi _2^{*} \rangle = 0\), і загальна інтенсивність є сумою інтенсивностей окремих випромінювачів:

    \(\seteqnumber{0}{3.}{15}\)

    \begin{equation*} I = I_1 + I_2. \end{equation*}

    Випромінювання двох різних природних джерел світла є некогерентним.

Величину \(\Gamma = \langle \phi _1 \phi _2^{*} \rangle \), яку можна вимірювати за допомогою радіофізичних та оптичних пристроїв, називають функцією взаємної когерентності. Тут \(\phi _1\) та \(\phi _2\) можуть бути двома різними полями, або значеннями одного й того ж поля у різних точках:

\(\seteqnumber{0}{3.}{15}\)

\begin{equation*} \phi _1 = \phi (t_1, \vect {r}_1), \quad \phi _2 = \phi (t_2, \vect {r}_2) \end{equation*}

Величину

\(\seteqnumber{0}{3.}{15}\)

\begin{equation*} \gamma = \frac {\langle \phi _1 \phi _2^{*} \rangle }{|\phi _1\|\phi _2|}, \quad \text {де } |\phi _i| \equiv \sqrt {\langle \phi _i \phi _i^{*} \rangle }, \quad i = 1, 2, \end{equation*}

називають ступенем взаємної когерентності. Саме ця величина визначає контрастність смуг в інтерференційній картині від двох пучків світла.

Оскільки, за нерівністю Коші-Буняковського5, \(|\langle \phi _1 \phi _2^{*} \rangle | \leqslant |\phi _1\|\phi _2|\), маємо \(|\gamma | \leqslant 1\).

5 Для будь-якого комплексного \(\lambda \) величина \(Z = \langle (\phi + \lambda \psi )(\phi ^{*} + \lambda ^{*} \psi ^{*}) \rangle \) — невід’ємна. Покладемо \(\lambda = -\langle \psi \phi ^{*} \rangle / \langle |\psi |^2 \rangle \), тоді \(Z = \langle |\phi |^2 \rangle - |\langle \psi \phi ^{*} \rangle |^2 / \langle |\psi |^2 \rangle \), звідки й випливає потрібне.

Поляризація випромінювання

При розгляді поляризації треба зважати на векторну природу польових функцій, зокрема, напруженості електричного поля. Зауважимо, що для фіксованого напрямку випромінювання досить розглядати лише електричне поле; воно визначає також і вектор напруженості магнітного поля.

Розглянемо поле випромінювання, що поширюється в напрямку осі \(x_3\), з напруженістю електричного поля \(\Efield = (E_1, E_2, 0)\), причому будемо вважати, що поле є суперпозицією монохроматичних хвиль \(\sim e^{-i\omega t}\) з близькими частотами. Напрямок вектора \(\Efield \), що є ортогональним напрямку поширення хвилі, визначає поляризацію (рис. 3.1).

Для випадкового поля \(\Efield \) введемо тензор поляризації:

\(\seteqnumber{0}{3.}{15}\)

\begin{equation} \rho _{ij} = \frac {\langle E_i E_j^{*} \rangle }{\langle |E_1|^2 \rangle + \langle |E_2|^2 \rangle }, \quad i, j = 1, 2 \label {eq:polarization_tensor} \end{equation}

Очевидно, матриця \(\|\rho \|\) є ермітовою, а її шпур (слід) дорівнює одиниці:

\(\seteqnumber{0}{3.}{16}\)

\begin{equation} \label {eq:hermitian} \rho _{ji} = \rho _{ij}^{*}, \quad \rho _{11} + \rho _{22} = 1 \end{equation}

Для цілком поляризованого випромінювання маємо \(E_i = N_i f(t)\), де \(f\) може бути випадковою функцією, але вектор \(N_i\), що визначає напрямок поля, є фіксованим. В цьому випадку \(\rho _{ij}\) пропорційне \(N_i N_j^{*}\) і:

\(\seteqnumber{0}{3.}{17}\)

\begin{equation} \det \|\rho \| = 0 \end{equation}

У випадку природного світла присутні усі можливі поляризації, що є рівноправними, причому \(\langle E_1 E_2^{*} \rangle = 0\), \(\langle |E_1|^2 \rangle = \langle |E_2|^2 \rangle \). В цьому разі:

\(\seteqnumber{0}{3.}{18}\)

\begin{equation*} \rho _{ij} = \frac {1}{2} \delta _{ij} \end{equation*}

В загальному випадку визначник матриці \(\|\rho \|\) є:

\(\seteqnumber{0}{3.}{18}\)

\begin{equation*} \det \|\rho \| = \rho _{11} \rho _{22} - |\rho _{12}|^2 = \frac {\langle |E_1|^2 \rangle \langle |E_2|^2 \rangle - |\langle E_1 E_2^{*} \rangle |^2}{ \left (\langle |E_1|^2 \rangle + \langle |E_2|^2 \rangle \right )^2} \end{equation*}

Оскільки \(|\langle E_1 E_2^{*} \rangle |^2 \leqslant \langle |E_1|^2 \rangle \langle |E_2|^2 \rangle \), цей визначник додатний:

\(\seteqnumber{0}{3.}{18}\)

\begin{equation*} \det \|\rho \| \geqslant 0 \end{equation*}

З іншого боку, очевидно:

\(\seteqnumber{0}{3.}{18}\)

\begin{equation*} \det \|\rho \| \leqslant \frac {\langle |E_1|^2 \rangle \, \langle |E_2|^2 \rangle } {\left (\langle |E_1|^2 \rangle + \langle |E_2|^2 \rangle \right )^2} \leqslant \frac {1}{4} \end{equation*}

Оскільки область значень \(\det \|\rho \| \) є відрізком \([0, 1/4]\), можна записати:

\(\seteqnumber{0}{3.}{18}\)

\begin{equation} \det \|\rho \| = \frac {1}{4} \left ( 1 - p^2 \right ),\quad \text {де}\ 0 \leqslant p \leqslant 1 \label {eq:polarization_degree} \end{equation}

де параметр \(p\) називають ступенем поляризації; він приймає значення від 0 (неполяризоване світло) до 1.

Завдяки властивості (3.17) (ермітовості), власні числа \(\lambda _1, \lambda _2\) матриці \(\rho _{ij}\) є дійсними, причому \(\det \|\rho \| = \lambda _1 \lambda _2\), \(\lambda _1 + \lambda _2 = 1\). Зважаючи на (3.19), добуток власних чисел додатний, тобто вони мають один знак. Звідси легко бачити, що ці числа є додатними. Якщо матриця \(\|\rho \|\) — дійсна, її можна привести до діагонального виду \(\| \rho \| = \mathrm {diag}(\lambda _{\min }, \lambda _{\max })\) за допомогою просторових поворотів. Частку \(\lambda _{\min }/\lambda _{\max }\) називають коефіцієнтом деполяризації.

Параметри Стокса

Виходячи з властивостей тензора поляризації, поданих формулою (3.16), його компоненти \(\rho _{ij}\) можна виразити через три незалежні дійсні параметри Стокса \(\xi _1, \xi _2, \xi _3\), які приймають значення від \(-1\) до \(1\):

\(\seteqnumber{0}{3.}{19}\)

\begin{equation*} \rho _{11} = \frac {1}{2} \left ( 1 + \xi _3 \right ), \quad \rho _{22} = \frac {1}{2} \left ( 1 - \xi _3 \right ), \quad \rho _{12} = \frac {1}{2} \left ( \xi _1 - i\xi _2 \right ) = \rho _{21}^{*} \end{equation*}

Очевидно:

\(\seteqnumber{0}{3.}{19}\)

\begin{equation*} \det \|\rho \| = \frac {1}{4} \left ( 1 - \xi _1^2 - \xi _2^2 - \xi _3^2 \right ) \end{equation*}

\(\seteqnumber{0}{3.}{19}\)

\begin{equation*} p^2 = \xi _1^2 + \xi _2^2 + \xi _3^2, \quad 0 \leqslant \xi _1^2 + \xi _2^2 + \xi _3^2 \leqslant 1 \end{equation*}

Розглянемо стани поляризації для деяких полів, що відповідають різним параметрам Стокса.

  • • Лінійна поляризація під кутом \(45^{\circ }\), тобто \(E_1 = \pm E_2\):

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \rho _{11} = \rho _{22} = \frac {1}{2} \rightarrow \xi _3 = 0; \quad \text {Im} \, \rho _{12} = 0 \rightarrow \xi _2 = 0; \end{equation*}

    Таким чином:

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \xi _1 = \pm 1, \quad \xi _3 = \xi _2 = 0 \end{equation*}

  • • Колова поляризація \(E_1 = A e^{-i\omega t}, \quad E_2 = \pm i E_1\).

    Як видно з поведінки дійсних частин компонент, вектор \(\Efield \) обертається в площині \(X_1 - X_2\). Маємо:

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \rho _{11} = \frac {1}{2}, \quad \rho _{22} = \frac {1}{2}, \quad \rho _{12} = \mp \frac {i}{2} \end{equation*}

    Звідси:

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \xi _1 = \xi _3 = 0, \quad \xi _2 = \pm 1 \end{equation*}

  • • Лінійна поляризація вздовж однієї з осей \(E_1 \neq 0, E_2 = 0\) або \(E_2 \neq 0, E_1 = 0\):

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \rho _{11} = 1, \quad \rho _{22} = 0 \rightarrow \xi _3 = 1, \end{equation*}

    або

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \rho _{11} = 0, \quad \rho _{22} = 1 \rightarrow \xi _3 = -1, \end{equation*}

    при цьому \(\rho _{12} = 0 \rightarrow \xi _1 = \xi _2 = 0\).

    Таким чином:

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \xi _1 = \xi _2 = 0, \quad \xi _3 = \pm 1 \end{equation*}

  • • Еліптична поляризація — загальний випадок: \(E_2 = A e^{i\delta } E_1\) з довільною амплітудою \(A\) та зсувом фаз \(\delta \). Тоді кінець вектора \(\Efield \) описує еліпс у площині \(X_1\!-\!X_2\), а компоненти тензора поляризації є нетривіальними:

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \rho _{11} = \frac {1}{1 + A^2}, \quad \rho _{22} = \frac {A^2}{1 + A^2}, \quad \rho _{12} = \frac {A e^{-i\delta }}{1 + A^2} \end{equation*}

    Звідси всі три параметри Стокса, взагалі кажучи, відмінні від нуля:

    \(\seteqnumber{0}{3.}{19}\)

    \begin{equation*} \xi _3 = \frac {1 - A^2}{1 + A^2}, \quad \xi _1 = \frac {2A\cos \delta }{1 + A^2}, \quad \xi _2 = \frac {2A\sin \delta }{1 + A^2} \end{equation*}

    причому \(\xi _1^2 + \xi _2^2 + \xi _3^2 = 1\). Лінійна (\(\delta = 0,\, \pi \)) та кругова (\(A = 1,\, \delta = \pm \pi /2\)) поляризації є граничними випадками.

Сфера Пуанкаре

Параметри Стокса \((\xi _1, \xi _2, \xi _3)\) зручно інтерпретувати як декартові координати точки на сфері радіуса \(p = 1\) (ступінь поляризації). Стан поляризації цілком поляризованого випромінювання (\(p = 1\)) однозначно задається точкою на одиничній сфері \(\xi _1^2 + \xi _2^2 + \xi _3^2 = 1\) — сфері Пуанкаре (рис. 3.6)6. Лінійні та кругові поляризації займають на ній особливі положення (полюси та точки екватора), тоді як еліптична поляризація відповідає всім решта точкам поверхні. Частково поляризоване світло зображується точкою всередині сфери, а неполяризоване — її центром.

Вигляд поляризації у площині \(X_1\!-\!X_2\) повністю визначається двома кутами: кутом нахилу великої осі \(\psi \in (-90^{\circ }, 90^{\circ })\) та кутом еліптичності \(\chi \in (-45^{\circ }, 45^{\circ })\), де \(\tg \chi = b/a\) — відношення малої півосі до великої, зі знаком що визначає напрямок обертання (\(\chi > 0\) — проти годинникової стрілки). Зв’язок цих кутів з параметрами Стокса:

\(\seteqnumber{0}{3.}{19}\)

\begin{equation*} \xi _1 = \cos 2\chi \cos 2\psi , \quad \xi _2 = \sin 2\chi , \quad \xi _3 = \cos 2\chi \sin 2\psi \end{equation*}

Обернені формули:

\(\seteqnumber{0}{3.}{19}\)

\begin{equation*} \psi = \tfrac {1}{2}\arctan \frac {\xi _1}{\xi _3}, \quad \chi = \tfrac {1}{2}\arcsin \xi _2 \end{equation*}

Таким чином, кути \(\psi \) і \(\chi \) грають роль довготи й широти на сфері Пуанкаре. Граничні випадки: \(\chi = 0\) — лінійна поляризація під кутом \(\psi \); \(\chi = \pm 45^{\circ }\) — кругова.

6 Сфера Пуанкаре перетворює задачу про поляризацію на задачу обертань цієї сфери: дія кожного поляризаційного елемента (фазова пластинка, обертач тощо) описується поворотом сфери на певний кут навколо певної осі. Це дозволяє наочно й без громіздких обчислень передбачати результат дії будь-якої оптичної системи на поляризоване світло.

3.3 Співвідношення між тривалістю сигналу та шириною його спектру

Міркування цього розділу застосовні до будь-яких сигналів чи хвильових полів, що можна аналізувати за допомогою перетворення Фур’є, зокрема, до хвильових пакетів, які є суперпозицією плоских хвиль з різними частотами.

Нехай маємо деякий сигнал (чи хвильове поле у деякій фіксованій точці), який описуємо за допомогою функції \(\phi (t)\) (взагалі кажучи, комплексної) від дійсної змінної \(t\), причому для цієї функції існує перетворення Фур’є:

\(\seteqnumber{0}{3.}{19}\)

\begin{equation} \label {eq:Fourier} {\phi }(t) = \frac 1{\sqrt {2\pi }} \int \limits _{-\infty }^{+\infty } \tilde \phi (\omega )\, e^{-i\omega t}\, d\omega . \end{equation}

Вважатимемо, що \(\phi (t)\) та \(\tilde {\phi }(\omega )\) досить швидко спадають, якщо відповідно \(|t| \to \infty \) та \(|\omega | \to \infty \).

Введемо величини, що характеризують тривалість сигналу \(\D t\) та ширину його спектру \(\D \omega \). Середні значення фізичних величин, що відповідають \(\phi (t)\), обчислюватимемо з вагою \(|\phi (t)|^2\) в \(t\)-просторі, а в \(\omega \)-просторі — з вагою \(|\tilde {\phi }(\omega )|^2\), причому, не зменшуючи загальності, приймемо умову нормування7:

\(\seteqnumber{0}{3.}{20}\)

\begin{equation} \label {eq:norm} \int \limits _{-\infty }^{+\infty } |\phi (t)|^2\, dt = 1. \end{equation}

Звідси, за рівністю Парсеваля (3.3) маємо

\(\seteqnumber{0}{3.}{21}\)

\begin{equation*} \int \limits _{-\infty }^{+\infty } |{\phi }(t)|^2\, dt = \int \limits _{-\infty }^{+\infty } |\tilde {\phi }(\omega )|^2\, d\omega = 1, \end{equation*}

тобто спектр \(\tilde {\phi }(\omega )\) також є нормованим.

Означимо середнє значення часу процесу:

\(\seteqnumber{0}{3.}{21}\)

\begin{equation*} \langle t \rangle = \int \limits _{-\infty }^{+\infty } t\, |\phi (t)|^2\, dt. \end{equation*}

Зручно вибрати відлік часу таким чином, щоб \(\langle t \rangle = 0\).

Природно оцінити тривалість процесу \(\phi (t)\) через середньоквадратичне відхилення \(\sqrt {\langle t^2 \rangle }\), де

\(\seteqnumber{0}{3.}{21}\)

\begin{equation} \label {eq:Delta_t} \langle \D t^2 \rangle = \int \limits _{-\infty }^{+\infty } (t - \langle t \rangle )^2\, |\phi (t)|^2\, dt \end{equation}

У \(\omega \)-просторі середнє значення частоти є:

\(\seteqnumber{0}{3.}{22}\)

\begin{equation*} \langle \omega \rangle = \int \limits _{-\infty }^{+\infty } \omega \, |\tilde {\phi }(\omega )|^2\, d\omega , \end{equation*}

а ширину спектра частот опишемо величиною

\(\seteqnumber{0}{3.}{22}\)

\begin{equation} \label {eq:Delta_omega} \langle \D \omega ^2 \rangle = \int \limits _{-\infty }^{+\infty } (\omega - \langle \omega \rangle )^2\, |\tilde {\phi }(\omega )|^2\, d\omega . \end{equation}

Покажемо, що існує спільне обмеження на величини \(\langle \D t^2 \rangle \) та \(\langle \D \omega ^2 \rangle \). Для цього перепишемо (3.22) через перетворення Фур’є.

\(\seteqnumber{0}{3.}{23}\)

\begin{equation*} t \phi (t) = \frac {1}{\sqrt {2\pi }} \int d\omega \cdot i \left (\frac {d}{d\omega }e^{-i\omega t}\right ) \tilde \phi (\omega ) = \frac {1}{\sqrt {2\pi }} \int d\omega \cdot e^{-i\omega t} \left ( -i \frac {d\tilde \phi }{d\omega } \right ), \end{equation*}

тобто помноження на \(t \) індукує диференціювання у просторі частот. Тоді формулу (3.22) можна переписати так:

\(\seteqnumber{0}{3.}{23}\)

\begin{equation} \langle \D t^2 \rangle = \int dt \cdot t^2 |\phi (t)|^2 = \int d\omega \left | \frac {d\tilde {\phi }}{d\omega } \right |^2 \label {eq:time_duration_fourier} \end{equation}

де застосовано рівність Парсеваля (3.3).

Для будь-якого дійсного \(x \):

\(\seteqnumber{0}{3.}{24}\)

\begin{equation*} 0 \leqslant \int d\omega \left | x \frac {d\tilde \phi }{d\omega } + (\omega - \omega _a) \tilde \phi \right |^2 \equiv \int d\omega \left ( x \frac {d\tilde \phi }{d\omega } + (\omega - \omega _a) \tilde \phi \right ) \left ( x \frac {d\tilde \phi ^{*}}{d\omega } + (\omega - \omega _a) \tilde \phi ^{*} \right ). \end{equation*}

Звідси, після застосування усереднення, за допомогою (3.23) та (3.24), маємо:

\(\seteqnumber{0}{3.}{24}\)

\begin{equation*} 0 \leqslant x^2 \langle \D t^2 \rangle + \langle \D \omega ^2 \rangle + x \int d\omega (\omega - \omega _a) \left [ \frac {d\tilde \phi }{d\omega } \tilde \phi ^{*} + \frac {d\tilde \phi ^{*}}{d\omega } \tilde \phi \right ]. \end{equation*}

Вираз у квадратних дужках в останньому доданку є повною похідною, тому інтеграл у правій частині нерівності перетворимо так:

\(\seteqnumber{0}{3.}{24}\)

\begin{equation*} \int d\omega (\omega - \omega _a) \frac {d}{d\omega } (\tilde \phi \tilde \phi ^{*}) = -\int d\omega |\tilde \phi |^2 \frac {d}{d\omega } (\omega - \omega _a) = - \int d\omega \left | \tilde \phi \right |^2 = -1. \end{equation*}

Таким чином:

\(\seteqnumber{0}{3.}{24}\)

\begin{equation*} x^2 \langle \D t^2 \rangle + \langle \D \omega ^2 \rangle - x \geqslant 0. \end{equation*}

Це співвідношення має виконуватися для будь-яких \(x\), тому дискримінант квадратного тричлена має бути від’ємним. Звідси маємо нерівність:

\(\seteqnumber{0}{3.}{24}\)

\begin{equation} \label {eq:uncertainty} \langle \D t^2 \rangle \cdot \langle \D \omega ^2 \rangle \geqslant \frac 14, \end{equation}

яку часто називають співвідношенням невизначеностей8.

Слід підкреслити, що співвідношення невизначеностей (3.25) було отримано для конкретних оцінок тривалості процесу (3.22) та ширини спектра частот (3.23). З цього співвідношення випливає, що сигнал, близький до монохроматичного, тобто такий, що має малий розкид частот, має бути досить тривалим. Навпаки, короткочасний сигнал має широкий спектр частот. Нерівність, аналогічну (3.25), можна отримати для довжини хвильового пакета у певному напрямі та ширини інтервалу відповідних хвильових векторів.

7 Умова (3.21) не зменшує загальності. Якщо її не накладати, усі міркування проводяться аналогічно, але у визначеннях середніх потрібно було б ділити на \(\displaystyle \int \limits _{-\infty }^{+\infty }|\phi (t)|^2\,dt\).

8 У квантовій механіці співвідношення (3.25) має аналог у вигляді зв’язку між тривалістю процесу та невизначеністю енергії. У випадку довжини пакета та розкиду хвильових векторів квантовий відповідник (3.25) — співвідношення невизначеностей для імпульсу та координати.

3.4 Загальний розв’язок рівнянь вільного поля

Далі буде отримано загальний розв’язок рівнянь Максвелла за відсутності джерел (\(\rho = 0\), \(\vect {j} = 0\)). В цьому разі система рівнянь поля є однорідною й описує вільні електромагнітні хвилі. Загальний розв’язок неоднорідних рівнянь Максвелла (за наявності зарядів та струмів) може бути побудований як суперпозиція загального розв’язку однорідних рівнянь вільного поля та часткового розв’язку неоднорідних рівнянь.

Скористуємось калібруванням Гамільтона (2.13):

\(\seteqnumber{0}{3.}{25}\)

\begin{equation} \phi = 0 \label {eq:phi_zero} \end{equation}

З рівняння (3.11) за умови \(\rho = 0\) маємо:

\(\seteqnumber{0}{3.}{26}\)

\begin{equation*} \frac {\partial }{\partial t} (\Div \vect {A}) = 0 \end{equation*}

Відкидаючи незалежні від часу ненульові розв’язки (що описують статичні поля, а не електромагнітні хвилі), дістанемо:

\(\seteqnumber{0}{3.}{26}\)

\begin{equation} \Div \vect {A} = 0 \label {eq:div_A_zero} \end{equation}

За цією умовою рівняння (2.15) зводиться до однорідного хвильового рівняння:

\(\seteqnumber{0}{3.}{27}\)

\begin{equation} \frac {1}{c^2} \frac {\partial ^2 \vect {A}}{\partial t^2} - \Laplasian \vect {A} = 0 \label {eq:wave_equation_A} \end{equation}

Шукатимемо розв’язок рівняння (3.28) в усьому просторі за допомогою просторового перетворення Фур’є:

\(\seteqnumber{0}{3.}{28}\)

\begin{equation} \vect {A}_{\vect {k}}(t) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {r} \cdot e^{-i\vect {k} \cdot \vect {r}} \vect {A}(t, \vect {r}) \label {eq:fourier_transform_A} \end{equation}

Обернене перетворення:

\(\seteqnumber{0}{3.}{29}\)

\begin{equation} \vect {A}(t, \vect {r}) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \cdot e^{i\vect {k} \cdot \vect {r}} \vect {A}_{\vect {k}}(t) \label {eq:inverse_fourier_transform_A} \end{equation}

дозволяє знайти напруженості електромагнітного поля за формулами (2.1) та (2.2) за відомим \(\vect {A}_{\vect {k}}(t)\).

Дія оператора Лапласа:

\(\seteqnumber{0}{3.}{30}\)

\begin{equation*} \Laplasian \vect {A}(t, \vect {r}) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \, \Laplasian \left ( e^{i\vect {k} \cdot \vect {r}} \right ) \vect {A}_{\vect {k}}(t) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \, e^{i\vect {k} \cdot \vect {r}} (-k^2) \vect {A}_{\vect {k}}(t) \end{equation*}

індукує домноження Фур’є-образу на \((-\vect {k}^2)\). Тому з рівняння (3.28) дістаємо:

\(\seteqnumber{0}{3.}{30}\)

\begin{equation} \frac {\partial ^2 \vect {A}_{\vect {k}}(t)}{\partial t^2} + \omega _{\vect {k}}^2 \vect {A}_{\vect {k}}(t) = 0 \label {eq:oscillator_equation} \end{equation}

де \(\omega _{\vect {k}} = ck = c|\vect {k}|\).

Рівняння (3.27) дає умову поперечності:

\(\seteqnumber{0}{3.}{31}\)

\begin{equation} \vect {k} \cdot \vect {A}_{\vect {k}}(t) = 0 \label {eq:transverse_condition} \end{equation}

Загальний розв’язок рівняння (3.31) запишемо у вигляді:

\(\seteqnumber{0}{3.}{32}\)

\begin{equation} \vect {A}_{\vect {k}}(t) = \vect {C}_1(\vect {k}) e^{i\omega _{\vect {k}} t} + \vect {C}_2(\vect {k}) e^{-i\omega _{\vect {k}} t}, \label {eq:general_solution_Ak} \end{equation}

де в силу (3.32):

\(\seteqnumber{0}{3.}{33}\)

\begin{equation*} \vect {C}_1(\vect {k}) \cdot \vect {k} = \vect {C}_2(\vect {k}) \cdot \vect {k} = 0 \end{equation*}

Звідси розв’язок хвильового рівняння (3.28) має вигляд:

\(\seteqnumber{0}{3.}{33}\)

\begin{equation} \vect {A}(t, \vect {r}) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \, \left ( \vect {C}_1(\vect {k}) e^{i\omega _{\vect {k}} t} + \vect {C}_2(\vect {k}) e^{-i\omega _{\vect {k}} t} \right ) e^{i\vect {k} \cdot \vect {r}} \label {eq:general_solution_A} \end{equation}

Оскільки вихідне поле \(\vect {A}(t, \vect {r})\) є дійсним, функції \(\vect {C}_1(\vect {k})\) та \(\vect {C}_2(\vect {k})\) не є незалежними. Маємо:

\(\seteqnumber{0}{3.}{34}\)

\begin{equation*} \vect {A}(t, \vect {r}) = \vect {A}^*(t, \vect {r}) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \, \left ( \vect {C}_1^*(\vect {k}) e^{-i\omega _{\vect {k}} t} + \vect {C}_2^*(\vect {k}) e^{i\omega _{\vect {k}} t} \right ) e^{-i\vect {k} \cdot \vect {r}} \end{equation*}

Після заміни \(\vect {k} \rightarrow -\vect {k}\) легко отримати:

\(\seteqnumber{0}{3.}{34}\)

\begin{equation*} \vect {A}(t, \vect {r}) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \, \left \{ \vect {C}_1^*(-\vect {k}) e^{-i\omega _{\vect {k}} t} + \vect {C}_2^*(-\vect {k}) e^{i\omega _{\vect {k}} t} \right \} e^{i\vect {k} \cdot \vect {r}}, \end{equation*}

де враховано \(\omega (\vect {k}) = c|\vect {k}| = \omega (-\vect {k})\).

Порівнюючи це з (3.34) і беручи до уваги незалежність \(e^{-i\omega _{\vect {k}} t}\) та \(e^{i\omega _{\vect {k}} t}\), отримаємо:

\(\seteqnumber{0}{3.}{34}\)

\begin{equation} \vect {C}_1^*(-\vect {k}) = \vect {C}_2(\vect {k}) \quad \text {або} \quad \vect {C}_1(\vect {k}) = \vect {C}_2^*(-\vect {k}), \label {eq:C1_C2_relation} \end{equation}

причому \(\vect {C}_1(\vect {k}) \cdot \vect {k} = 0\).

Подамо цей розв’язок у дещо іншій формі, виділивши лоренц-інваріантні величини \(\omega _{\vect {k}} - \vect {k} \cdot \vect {r}\).

У першому доданку в (3.34) за допомогою заміни \(\vect {k} \rightarrow -\vect {k}\) зробимо очевидні перетворення:

\(\seteqnumber{0}{3.}{35}\)

\begin{equation*} \int \vect {C}_1(\vect {k}) e^{i(\omega _{\vect {k}} t + \vect {k} \cdot \vect {r})} d^3\vect {k} = \int \vect {C}_1(-\vect {k}) e^{i(\omega _{\vect {k}} t - \vect {k} \cdot \vect {r})} d^3\vect {k} = \int \vect {C}_2^*(\vect {k}) e^{i(\omega _{\vect {k}} t - \vect {k} \cdot \vect {r})} d^3\vect {k}. \end{equation*}

Позначаючи \(\vect {a}(\vect {k}) = \vect {C}_2(\vect {k}) = \vect {C}_1^*(-\vect {k})\), маємо представлення розв’язку у вигляді:

\(\seteqnumber{0}{3.}{35}\)

\begin{equation} \vect {A}(t, \vect {r}) = \frac {1}{(2\pi )^{3/2}} \int \left ( \vect {a}(\vect {k}) e^{-i(\omega _{\vect {k}} t - \vect {k} \cdot \vect {r})} + \vect {a}^*(\vect {k}) e^{i(\omega _{\vect {k}} t - \vect {k} \cdot \vect {r})} \right ) d^3\vect {k} \label {eq:A_final_form} \end{equation}

Формула (3.36) з умовою поперечності \(\vect {k} \cdot \vect {a}(\vect {k}) = 0\) подає загальний розв’язок хвильового рівняння (3.28) з умовою (3.27).

Доданок, що містить \(e^{-i(\omega _{\vect {k}} t - \vect {k} \cdot \vect {r})}\), називають додатно-частотною частиною поля, а комплексно-спряжений йому доданок — від’ємно-частотною частиною. Представлення (3.36) називають розбиттям на додатно-частотні та від’ємно-частотні компоненти9.

Як бачимо з (3.36), стан вільного електромагнітного поля визначається, з огляду на умову поперечності \(\vect {k} \cdot \vect {a} = 0\), двома комплексними функціями від трьох змінних \(\vect {k}\), або — еквівалентно — чотирма дійсними функціями від \(\vect {k}\). Кількість цих незалежних функцій (яка відповідає ступеням вільності поля) така ж, як у задачі Коші згідно з п. 2.3.

Кожному \(\vect {k}\) відповідає плоска хвиля \(\vect {a}(\vect {k}) e^{i(\omega _{\vect {k}} t - \vect {k} \cdot \vect {r})}\) — частковий розв’язок рівняння (3.28), причому напрямок вектора \(\vect {a}(\vect {k})\) задає поляризацію.

9 Розбиття сигналу на додатно-частотні та від’ємно-частотні компоненти використовують у цифровій обробці сигналів.

Розклад поля на осцилятори

За допомогою заміни \(\vect {k} \rightarrow -\vect {k}\) у від’ємно-частотній частині перепишемо (3.36) у вигляді:

\(\seteqnumber{0}{3.}{36}\)

\begin{equation} \vect {A}(t, \vect {r}) = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \, \left ( \vect {a}(\vect {k}) e^{-i\omega _{\vect {k}} t} + \vect {a}^*(-\vect {k}) e^{i\omega _{\vect {k}} t} \right ) e^{i\vect {k} \cdot \vect {r}} \label {eq:A_final_form_modified} \end{equation}

Згідно з (2.2), (2.1) та калібрувальною умовою (3.26):

\(\seteqnumber{0}{3.}{37}\)

\begin{equation} \Efield = -\frac {1}{c} \frac {\partial \vect {A}}{\partial t} = \frac {i}{(2\pi )^{3/2}} \int d^3\vect {k} \, \omega _{\vect {k}} \left ( \vect {a}(\vect {k}) e^{-i\omega _{\vect {k}} t} - \vect {a}^*(-\vect {k}) e^{i\omega _{\vect {k}} t} \right ) e^{i\vect {k} \cdot \vect {r}} \label {eq:E_field_fourier} \end{equation}

Обчислимо енергію електричного поля за допомогою формули Парсеваля:

\(\seteqnumber{0}{3.}{38}\)

\begin{multline*} W_E = \frac {1}{8\pi } \int \Efield ^2\ dV = \\ = \frac {1}{8\pi c^2} \int d^3\vect {k} \, \omega _{\vect {k}}^2 \left | \vect {a}(\vect {k})e^{-i\omega _{\vect {k}} t} - \vect {a}^*(-\vect {k})e^{i\omega _{\vect {k}} t} \right |^2 = \\ = \frac {1}{8\pi c^2} \int d^3\vect {k} \, \omega _{\vect {k}}^2 \left [ \vect {a}^*(\vect {k}) \cdot \vect {a}(\vect {k}) + \vect {a}^*(-\vect {k}) \cdot \vect {a}(-\vect {k}) \right . - \\ - \left . 2\Re \left ( \vect {a}(\vect {k}) \cdot \vect {a}(-\vect {k}) e^{-2i\omega _{\vect {k}} t} \right ) \right ] \end{multline*}

Оскільки:

\(\seteqnumber{0}{3.}{38}\)

\begin{equation*} \int d^3\vect {k}\ \omega ^2_{\vect {k}} \, \vect {a}^*(-\vect {k}) \cdot \vect {a}(-\vect {k}) = \int d^3\vect {k} \ \omega ^2_{\vect {k}} \vect {a}^*(\vect {k}) \cdot \vect {a}(\vect {k}), \end{equation*}

маємо:

\(\seteqnumber{0}{3.}{38}\)

\begin{equation} W_E = \frac {1}{4\pi c^2} \int d^3\vect {k} \, \omega _{\vect {k}}^2 \left [ \vect {a}^*(\vect {k}) \cdot \vect {a}(\vect {k}) - \Re \left ( \vect {a}(\vect {k}) \cdot \vect {a}(-\vect {k}) e^{-2i\omega _{\vect {k}} t} \right ) \right ] \label {eq:W_E_final} \end{equation}

Аналогічно:

\(\seteqnumber{0}{3.}{39}\)

\begin{equation*} \Bfield = \Rot \vect {A} = \frac {1}{(2\pi )^{3/2}} \int d^3\vect {k} \, \left [ \vect {k} \times \left ( \vect {a}(\vect {k}) e^{-i\omega _{\vect {k}} t} + \vect {a}^*(-\vect {k}) e^{i\omega _{\vect {k}} t} \right ) \right ] e^{i\vect {k} \cdot \vect {r}}, \end{equation*}

а енергія магнітного поля:

\(\seteqnumber{0}{3.}{39}\)

\begin{equation*} W_B = \frac {1}{8\pi } \int \Bfield ^2 dV = \frac {1}{8\pi } \int \left | \vect {k} \times \left ( \vect {a}(\vect {k}) e^{-i\omega _{\vect {k}} t} + \vect {a}^*(-\vect {k}) e^{i\omega _{\vect {k}} t} \right ) \right |^2 d^3\vect {k} \label {eq:W_B} \end{equation*}

Оскільки \(\vect {k} \cdot \vect {a}(\vect {k}) = 0\), маємо:

\(\seteqnumber{0}{3.}{39}\)

\begin{equation*} \left | \vect {k} \times \vect {a}(\vect {k}) \right |^2 = \vect {k}^2 \vect {a}^*(\vect {k}) \cdot \vect {a}(\vect {k}), \end{equation*}

а також:

\(\seteqnumber{0}{3.}{39}\)

\begin{equation*} \left [ \vect {k} \times \vect {a}(\vect {k}) \right ] \cdot \left [ \vect {k} \times \vect {a}(-\vect {k}) \right ] = \vect {k}^2\ \vect {a}(\vect {k}) \cdot \vect {a}(-\vect {k}). \end{equation*}

Звідси, аналогічно (3.39):

\(\seteqnumber{0}{3.}{39}\)

\begin{equation} W_B = \frac {1}{4\pi } \int d^3\vect {k} \, \vect {k}^2\ \left [ \vect {a}^*(\vect {k}) \cdot \vect {a}(\vect {k}) + \Re \left ( \vect {a}(\vect {k}) \cdot \vect {a}(-\vect {k}) e^{-2i\omega _{\vect {k}} t} \right ) \right ] \label {eq:W_B_final} \end{equation}

Оскільки \(\omega _{\vect {k}} = c|\vect {k}|\), загальна енергія вільного електромагнітного поля:

\(\seteqnumber{0}{3.}{40}\)

\begin{equation} W = W_E + W_B = \frac {1}{2\pi c^2} \int d^3\vect {k} \, \omega _{\vect {k}}^2 \vect {a}^*(\vect {k}) \cdot \vect {a}(\vect {k}) \label {eq:total_energy} \end{equation}

Подамо цей вираз через нові змінні:

\(\seteqnumber{0}{3.}{41}\)

\begin{equation} \label {eq:Pk} \vect {P}_{\vect {k}} = \frac {\omega _{\vect {k}}}{2c\sqrt {\pi }} \left [ \vect {a}^*(\vect {k}) e^{i\omega _{\vect {k}} t} + \vect {a}(\vect {k}) e^{-i\omega _{\vect {k}} t} \right ] \end{equation}

\(\seteqnumber{0}{3.}{42}\)

\begin{equation} \label {eq:Qk} \vect {Q}_{\vect {k}} = \frac {1}{2ic\sqrt {\pi }} \left [ \vect {a}^*(\vect {k}) e^{i\omega _{\vect {k}} t} - \vect {a}(\vect {k}) e^{-i\omega _{\vect {k}} t} \right ] \end{equation}

Звідси:

\(\seteqnumber{0}{3.}{43}\)

\begin{equation*} \vect {a}(\vect {k}) = c\sqrt {\pi } \left [ \frac {\vect {P}_{\vect {k}}}{\omega _{\vect {k}}} - i\vect {Q}_{\vect {k}} \right ] e^{i\omega _{\vect {k}} t}, \end{equation*}

\(\seteqnumber{0}{3.}{43}\)

\begin{equation*} \vect {a}^*(\vect {k}) = c\sqrt {\pi } \left [ \frac {\vect {P}_{\vect {k}}}{\omega _{\vect {k}}} + i\vect {Q}_{\vect {k}} \right ] e^{-i\omega _{\vect {k}} t}. \end{equation*}

\(\seteqnumber{0}{3.}{43}\)

\begin{equation*} \vect {P}_{\vect {k}} \cdot \vect {k} = 0, \quad \vect {Q}_{\vect {k}} \cdot \vect {k} = 0. \end{equation*}

За допомогою цих співвідношень отримаємо такий вираз для загальної енергії поля (3.41):

\(\seteqnumber{0}{3.}{43}\)

\begin{equation} W = \frac 12 \int d^3\vect {k} \left ( \vect {P}^2_{\vect {k}} + \omega ^2_{\vect {k}}\vect {Q}^2_{\vect {k}}\right ), \end{equation}

що має вигляд гамільтоніана континуальної системи осциляторів з частотою \(\omega _{\vect {k}}\). Цю формулу називають розкладом поля на осцилятори. Зауважимо, що для кожного \(\vect {k}\):

\(\seteqnumber{0}{3.}{44}\)

\begin{equation*} \dot {\vect {Q}}_{\vect {k}} = \vect {P}_{\vect {k}}, \quad \dot {\vect {P}}_{\vect {k}} = - \omega ^2_{\vect {k}} \vect {Q}_{\vect {k}}. \end{equation*}

що випливає як з гамільтонової форми рівнянь руху відповідно до (3.41), так і безпосередньо з рівнянь (3.42), (3.43). «Координати» задовольняють рівнянням:

\(\seteqnumber{0}{3.}{44}\)

\begin{equation*} \ddot {\vect {Q}}_{\vect {k}} + \omega ^2_{\vect {k}}\vect {Q}_{\vect {k}} = 0 \end{equation*}

та описують коливання поля з частотою \(\omega _{\vect {k}}\)10.

Це означає, що, кожна мода поля з хвильовим вектором \(\vect {k}\) поводиться як незалежний гармонічний осцилятор з частотою \(\omega _{\vect {k}}\). Хоча таке представлення електромагнітного поля в класичній електродинаміці видається не більш ніж зручним математичним описом, але воно має принципове значення при переході до квантової теорії. Поле набуває вигляду суми незалежних осциляторів, що дозволяє застосувати стандартну процедуру квантування, відпрацьовану для систем зі скінченним числом ступеней свободи.

10 Ці рівняння повністю збігаються з рівняннями гармонічного осцилятора з класичної механіки:

\[ \dot {q} = p,\quad \dot {p} = -\omega ^2 q,\quad \ddot {q} + \omega ^2 q = 0. \]
