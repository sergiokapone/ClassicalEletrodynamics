Розділ 9 Тензор енергії-імпульсу і закони збереження

В цьому розділі будуть отримані закони збереження енергії-імпульсу та моменту імпульсу як наслідок рівнянь електродинаміки в коваріантній формі та введено тензор енергії-імпульсу електромагнітного поля.

9.1 Чотири-імпульс системи тіл

Перепишемо рівняння руху частинки в зовнішньому електромагнітному полі за допомогою вектора 4-імпульсу, який означимо так:

\(\seteqnumber{0}{9.}{0}\)

\begin{equation*} p^{\mu } = mc\,u^{\mu }. \end{equation*}

Очевидно, завдяки співвідношенню \(u^{\mu }u_{\mu }=1\), маємо

\(\seteqnumber{0}{9.}{0}\)

\begin{equation} \label {eq:p_invariant} p^{\mu }p_{\mu } = m^2c^2. \end{equation}

Рівняння руху мають вид

\(\seteqnumber{0}{9.}{1}\)

\begin{equation*} \frac {dp^{\mu }}{ds} = \frac {q}{c}F^{\mu }{}_{\nu }\frac {dx^{\nu }}{ds}. \end{equation*}

Вибираючи час системи відліку як незалежної змінної, перепишемо це співвідношення у вигляді

\(\seteqnumber{0}{9.}{1}\)

\begin{equation} \label {eq:EOM_p} \frac {dp^{\mu }}{dt} = \frac {q}{c}F^{\mu }{}_{\nu }\frac {dx^{\nu }}{dt}, \end{equation}

з якого випливає фізичний зміст компонент \(p^{\mu }\). Дійсно, при \(\mu =0\), враховуючи представлення \(F^{\mu \nu }\) через електричне і магнітне поля, маємо

\(\seteqnumber{0}{9.}{2}\)

\begin{equation*} \frac {d\mathcal {E}}{dt} = q(\Efield \cdot \vect {v}), \end{equation*}

де \(\mathcal {E}=cp^0=mc^2/\sqrt {1-v^2/c^2}\), \(\vect {v}=d\vect {r}/dt\) — звичайна швидкість, або \(d\mathcal {E}=q(\Efield \cdot d\vect {r})\).

Права частина цього рівняння — робота електромагнітного поля, яке діє на частинку з зарядом \(q\) й передає їй певну енергію, зміна якої \(d\mathcal {E}\) фігурує в лівій частині.

При \(\mu =i=1,2,3\) з (9.2) у тривимірних позначеннях дістанемо

\(\seteqnumber{0}{9.}{2}\)

\begin{equation*} \frac {d\vect {p}}{dt} = q\!\left (\Efield + \frac {1}{c}\vect {v}\times \Bfield \right ), \end{equation*}

де \(\vect {p}=m\vect {v}(1-v^2/c^2)^{-1/2}\) — тривимірна частина 4-імпульсу. Це рівняння описує обмін імпульсом між зарядженим тілом та електромагнітним полем, причому права частина рівняння дає значення сили, що діє на тіло. Таким чином, \(\vect {p}\) має сенс імпульсу рухомого тіла.

З рівняння (9.1) випливає зв’язок між енергією та імпульсом:

\(\seteqnumber{0}{9.}{2}\)

\begin{equation*} \mathcal {E}^2 = m^2c^4 + \vect {p}^2c^2. \end{equation*}

Узагальнимо енергетичні співвідношення на випадок неперервного розподілу зарядів. Обмін 4-імпульсом між полем та системою \(N\) точкових тіл в області1 \(\Omega _3\) звичайного тривимірного простору описується рівнянням, яке випливає з (9.2):

\(\seteqnumber{0}{9.}{2}\)

\begin{equation*} \frac {dP^{\mu }}{dt} = \sum _{k=1}^{N}\frac {q_k}{c}F^{\mu }{}_{\nu }(x_k) \frac {dx_k^{\nu }}{dt}, \end{equation*}

де \(P^{\mu }=\sum _{k=1}^{N}p_k^{\mu }\) — 4-імпульс системи тіл.

У випадку неперервного розподілу перейдемо від сум до інтегрування:

\(\seteqnumber{0}{9.}{2}\)

\begin{equation} \label {eq:dPdt} \frac {dP^{\mu }}{dt} = \frac {1}{c}\int dq\cdot F^{\mu }{}_{\nu }\frac {dx^{\nu }}{dt} = \frac {1}{c}\int d^3\vect {r}\,\rho \,F^{\mu }{}_{\nu }\frac {dx^{\nu }}{dt} = \frac {1}{c}\int d^3\vect {r}\,F^{\mu }{}_{\nu }j^{\nu }. \end{equation}

Права частина (9.3) визначає 4-імпульс, який поле передає системі частинок за одиницю часу.

1 Тут вважаємо, що частинки не перетинають меж цієї області. Якщо це не виконується, в рівняннях збереження треба враховувати потік частинок через межу області.

  • 9.1. \(\pi ^0\)-Мезон, що рухається зі швидкістю \(v<c\), розпадається на два \(\gamma \)-кванти. Знайти мінімальний кут \(\theta _{\min }\) між напрямками розлітання квантів.

    Вказівка: з законів збереження енергії та імпульсу отримати

    \(\seteqnumber{0}{9.}{3}\)

    \begin{equation*} \sin ^2\!\frac {\theta }{2} = \frac {m^2c^4}{4\mathcal {E}_1\mathcal {E}_2}. \end{equation*}

    де \(\omega _1,\omega _2\) — частоти фотонів.

    Відповідь: \(\sin ^2(\theta _{\min }/2) = 1 - v^2/c^2\).

  • 9.2. Дві елементарні частинки перетворюються на дві інші за схемою \(a+b\to c+d\). Позначимо

    \(\seteqnumber{0}{9.}{3}\)

    \begin{equation*} s = (p_a^{\mu }+p_b^{\mu })(p_{a\mu }+p_{b\mu }), \ t = (p_a^{\mu }-p_c^{\mu })(p_{a\mu }-p_{c\mu }), \ u = (p_a^{\mu }-p_d^{\mu })(p_{a\mu }-p_{d\mu }), \end{equation*}

    де \(p_i^{\mu }\) — 4-імпульси частинок (\(i=a,b,c,d\)). Доведіть, що

    \(\seteqnumber{0}{9.}{3}\)

    \begin{equation*} s + t + u = m_a^2c^2 + m_b^2c^2 + m_c^2c^2 + m_d^2c^2, \end{equation*}

    де \(m_i\) — маси частинок.

  • 9.3. При зіткненні частинки з масою спокою \(m\) із нерухомою частинкою з масою спокою \(m_1\) відбувається реакція, після якої залишаються частинки із загальною масою спокою \(M\). Знайдіть мінімальне значення кінетичної енергії частинки, що налітає (енергетичний поріг реакції).

    Вказівка: Покажіть, що за умов задачі кінетична енергія частинок в системі центру мас є монотонною функцією енергії та імпульсу частинки, що налітає. В цій системі мінімальне значення енергії відповідає випадку, коли продукти реакції покояться. В лабораторній системі усі частинки мають однакову швидкість.

    Відповідь:

    \(\seteqnumber{0}{9.}{3}\)

    \begin{equation*} T_{\min } = \frac {(M^2 - m^2 - m_1^2)c^4}{2m_1c^2} - mc^2. \end{equation*}

    де \(T_{\min } = \mathcal {E}_{\min } - mc^2\) — мінімальна кінетична енергія частинки, що налітає.

9.2 Енергія-імпульс електромагнітного поля

Введемо, за означенням, тензор енергії-імпульсу електромагнітного поля:

\(\seteqnumber{0}{9.}{3}\)

\begin{equation} \label {eq:EMT} T^{\mu }{}_{\nu } = \frac {1}{4\pi }\!\left ( -F^{\mu \alpha }F_{\nu \alpha } + \frac {1}{4}\delta ^{\mu }_{\nu }F_{\alpha \beta }F^{\alpha \beta } \right ). \end{equation}

Знайдемо величину \(\partial _{\mu }T^{\mu }{}_{\nu }\), з урахуванням рівнянь Максвелла для \(F_{\mu \nu }\). Обчислимо спочатку допоміжне співвідношення, яке випливає з другої групи рівнянь Максвелла з урахуванням антисиметрії \(F_{\mu \nu }\):

\(\seteqnumber{0}{9.}{4}\)

\begin{multline*} F^{\alpha \beta } F_{\alpha \beta ,\nu } = - F^{\alpha \beta } \left ( F_{\beta \nu ,\alpha } + F_{\nu \alpha ,\beta } \right ) = \\ = - F^{\alpha \beta } \left ( - F_{\nu \beta ,\alpha } + F_{\nu \alpha ,\beta } \right ) = \\ = F^{\alpha \beta } F_{\nu \beta ,\alpha } - F^{\alpha \beta } F_{\nu \alpha ,\beta } = -F^{\alpha \beta } F_{\nu \alpha ,\beta } - F^{\alpha \beta } F_{\nu \alpha ,\beta } = -2 F^{\alpha \beta } F_{\nu \alpha ,\beta }, \end{multline*}

Звідси

\(\seteqnumber{0}{9.}{4}\)

\begin{equation*} \frac {\partial }{\partial x^\nu }\!\left (F^{\alpha \beta } F_{\alpha \beta }\right ) = 2 F^{\alpha \beta } F_{\alpha \beta ,\nu } = -4 F^{\alpha \beta } F_{\nu \alpha ,\beta }. \end{equation*}

Враховуючи це співвідношення та беручи до уваги першу групу рівнянь Максвелла (7.1), дістаємо:

\(\seteqnumber{0}{9.}{4}\)

\begin{align*} \partial _{\mu }T^{\mu }{}_{\nu } = \frac {1}{4\pi }\!\left ( -\partial _{\mu }F^{\mu \alpha }F_{\nu \alpha } - F^{\mu \alpha }F_{\nu \alpha ,\mu } - F^{\alpha \beta }F_{\nu \alpha ,\beta } \right ). \end{align*} Завдяки антисиметрії \(F_{\mu \nu }\) другий та останній доданки скорочуються, звідси:

\(\seteqnumber{0}{9.}{4}\)

\begin{equation} \label {eq:divT} \partial _{\mu }T^{\mu }{}_{\nu } = -\frac {1}{4\pi }\partial _{\mu }F^{\mu \alpha }F_{\nu \alpha } = -\frac {1}{c}F_{\nu \alpha }j^{\alpha }. \end{equation}

Права частина цього рівняння, згідно до (9.3), визначає 4-імпульс, що переходить від поля до зарядів в одиниці об’єму за одиницю часу. Піднімемо індекс \(\nu \) за допомогою метричного тензора та проінтегруємо (9.5) по тривимірному об’єму \(\Omega _3\), тоді права частина дасть втрати енергії поля всередині об’єму \(\Omega _3\) за одиницю часу. Ліва частина дає змогу отримати явний вираз для втрат 4-імпульсу (або його збільшення — залежно від знаку) через польові функції:

\(\seteqnumber{0}{9.}{5}\)

\begin{align*} \int \limits _{\Omega _3} d^3 x \, (\partial _\nu T^{\mu \nu }) & = \frac {1}{c}\,\frac {d}{dt} \int \limits _{\Omega _3} T^{\mu 0}\, d^3 x + \int \limits _{\Omega _3} d^3 x \, \frac {\partial T^{\mu i}}{\partial x^i} \\ & = \frac {1}{c}\,\frac {d}{dt} \int \limits _{\Omega _3} T^{\mu 0}\, d^3 x + \oint \limits _{\partial \Omega _3} T^{\mu i}\, d\sigma _i \, . \end{align*} де \(d\sigma _i\) — елемент площини поверхні \(\partial \Omega _3\), що обмежує просторову область \(\Omega _3\) (з \(d\sigma _1=dy\,dz\), \(d\sigma _2=dx\,dz\), \(d\sigma _3=dx\,dy\)), причому інтеграл по \(\partial \Omega _3\) описує потік 4-імпульсу через межу цієї області. Інтегральний закон збереження енергії та імпульсу усієї системи «поле + частинки» в цій області має такий вигляд:

\(\seteqnumber{0}{9.}{5}\)

\begin{equation} \label {eq:conservation_integral} \frac {dP^{\mu }}{dt} + \frac {1}{c}\frac {d}{dt}\int \limits _{\Omega _3}T^{\mu 0}\,d^3\vect {r} + \oint \limits _{\partial \Omega _3}T^{\mu j}\,d\sigma _j = 0, \end{equation}

де враховано (9.3), (9.5), причому тут вважаємо, що частинки не перетинають межі області \(\Omega _3\). Звідси \(T^{00}\) можна інтерпретувати як густину енергії електромагнітного поля, \(T^{i0}/c\) — як густину імпульсу. Останній доданок в (9.6) описує потік 4-імпульсу через поверхню \(\partial \Omega _3\); відповідно \(cT^{i0}=\Pi ^i\) описує компоненти тривимірного вектора густини потоку енергії, де \(\vect {\Pi }\) — вектор Пойнтінга.

Запишемо явні вирази для густини енергії поля:

\(\seteqnumber{0}{9.}{6}\)

\begin{equation} \label {eq:T00} T^{00} = \frac {1}{8\pi }\!\left (\Efield ^2 + \Bfield ^2\right ), \end{equation}

та для густини потоку енергії:

\(\seteqnumber{0}{9.}{7}\)

\begin{equation} \label {eq:Poynting} \vect {\Pi } = \frac {c}{4\pi }[\Efield \times \Bfield ]. \end{equation}

Як видно з (9.6) при \(\mu =0\), \(\oint \limits _{\partial \Omega _3}\vect {\Pi }\cdot d\vect {S}\) — це енергія, що витікає через \(\partial \Omega _3\) за одиницю часу. Одночасно \(T^{0i}/c = T^{i0}/c = \Pi ^i/c^2\) — густина імпульсу поля, причому рівняння (9.6) при \(\mu =i\) описує збереження імпульсу. Доданок \(\oint _{\partial \Omega _3}d\sigma _j T^{ij}\) описує потік імпульсу (імпульс, що витікає за одиницю часу через поверхню \(\partial \Omega _3\)). Відповідно, \(T^{k1}, T^{k2}, T^{k3}\) можна інтерпретувати як густину потоку \(k\)-тої компоненти імпульсу. Для просторової частини тензора енергії-імпульсу маємо \(T^{ij}=-t^{ij}\), де тривимірний тензор

\(\seteqnumber{0}{9.}{8}\)

\begin{equation} \label {eq:Maxwell_stress} t^{ij} = \frac {1}{4\pi }\!\left ( E^i E^j + B^i B^j - \frac {1}{2}\delta ^{ij}(\Efield ^2+\Bfield ^2) \right ) \end{equation}

називають максвелівським тензором напружень.

Наведемо також співвідношення, що випливає з явного виду (9.4) тензора енергії-імпульсу електромагнітного поля:

\(\seteqnumber{0}{9.}{9}\)

\begin{equation*} T^{\mu \nu }\eta _{\mu \nu } = 0. \end{equation*}

9.3 Тензор моменту імпульсу електромагнітної системи

У нерелятивістській теорії компоненти векторного добутку \(\vect {r}\times \vect {p}\), що складають момент імпульсу, можна записати як \(x^i p^j - x^j p^i\). Розглянемо узагальнення цього виразу

\(\seteqnumber{0}{9.}{9}\)

\begin{equation} \label {eq:M_particle} M^{\mu \nu } = x^{\mu }p^{\nu } - x^{\nu }p^{\mu }, \end{equation}

яке називають 4-тензором моменту імпульсу. Обчислимо, як змінюється ця величина вздовж траєкторії зарядженої частинки:

\(\seteqnumber{0}{9.}{10}\)

\begin{align*} \frac {d}{dt}M^{\mu \nu } & = \left (\frac {dx^{\mu }}{dt}p^{\nu } - \frac {dx^{\nu }}{dt}p^{\mu }\right ) + x^{\mu }\frac {dp^{\nu }}{dt} - x^{\nu }\frac {dp^{\mu }}{dt} \\ & = \frac {q}{c}\!\left ( x^{\mu }F^{\nu }{}_{\alpha }\frac {dx^{\alpha }}{dt} - x^{\nu }F^{\mu }{}_{\alpha }\frac {dx^{\alpha }}{dt} \right ), \end{align*} де враховані співвідношення \(p^{\nu }=mc\,u^{\nu }\), \(dx^{\mu }/dt=u^{\mu }\,ds/dt\), а також рівняння руху (9.2). Для системи частинок:

\(\seteqnumber{0}{9.}{10}\)

\begin{equation*} \frac {d}{dt}\sum _{\Omega }M^{\mu \nu } = \sum _{\Omega }\frac {q}{c}\!\left ( x^{\mu }F^{\nu }{}_{\alpha } - x^{\nu }F^{\mu }{}_{\alpha } \right )\frac {dx^{\alpha }}{dt}, \end{equation*}

де індекс під сумою означає, що вона береться за усіма частинками в області \(\Omega \).

При переході до неперервного розподілу обмін 4-моментом між системою частинок і полем можна записати так:

\(\seteqnumber{0}{9.}{10}\)

\begin{equation} \label {eq:dM_particles} \frac {d}{dt}\int \limits _{\Omega }M^{\mu \nu }\,dV = \frac {1}{c}\int \!\left ( x^{\mu }F^{\nu }{}_{\alpha } - x^{\nu }F^{\mu }{}_{\alpha } \right )j^{\alpha }\,dV, \end{equation}

де враховано, що для частинок в деякому об’ємі \(\D V\): \(\sum \limits _{\D V} q\,dx^{\alpha }/dt \to \rho \,(dx^{\alpha }/dt)\,\D V = j^{\alpha }\D V\).

Перейдемо до визначення моменту імпульсу електромагнітного поля. Розглянемо вираз:

\(\seteqnumber{0}{9.}{11}\)

\begin{equation} \label {eq:divM_field} \partial _{\alpha }\!\left (x^{\mu }T^{\nu \alpha } - x^{\nu }T^{\mu \alpha }\right ) = \delta ^{\mu }_{\alpha }T^{\nu \alpha } - \delta ^{\nu }_{\alpha }T^{\mu \alpha } + x^{\mu }T^{\nu \alpha }{}_{,\alpha } - x^{\nu }T^{\mu \alpha }{}_{,\alpha }. \end{equation}

Використовуючи рівняння (9.5) з урахуванням симетрії \(T^{\alpha \beta }\), дістанемо:

\(\seteqnumber{0}{9.}{12}\)

\begin{equation} \label {eq:divM_result} \partial _{\alpha }\!\left (x^{\mu }T^{\nu \alpha } - x^{\nu }T^{\mu \alpha }\right ) = -\frac {1}{c}\!\left ( x^{\mu }F^{\nu }{}_{\alpha } - x^{\nu }F^{\mu }{}_{\alpha } \right )j^{\alpha }. \end{equation}

Проінтегруємо це співвідношення по області \(\Omega _3\) із застосуванням формули Остроградського-Гауса:

\(\seteqnumber{0}{9.}{13}\)

\begin{multline*} \frac {1}{c} \int \limits _{\Omega _3} d^3 x \, \frac {\partial }{\partial t} \left ( x^\mu T^{\nu 0} - x^\nu T^{\mu 0} \right ) + \int \limits _{\Omega _3} d^3 x \, \frac {\partial }{\partial x^i} \left ( x^\mu T^{\nu i} - x^\nu T^{\mu i} \right ) = \\ =\frac {d\mathcal {M}^{\mu \nu }}{dt} + \oint \limits _{\partial \Omega _3}d\sigma _i\!\left (x^{\mu }T^{\nu i} - x^{\nu }T^{\mu i}\right ) = -\frac {1}{c}\int \limits _{\Omega _3}d^3\vect {r}\, \!\left (x^{\mu }F^{\nu }{}_{\alpha } - x^{\nu }F^{\mu }{}_{\alpha }\right )j^{\alpha }, \end{multline*}

де величину

\(\seteqnumber{0}{9.}{13}\)

\begin{equation*} \mathcal {M}^{\mu \nu } = \frac {1}{c}\int \limits _{\Omega _3}\!\left (x^{\mu }T^{\nu 0} - x^{\nu }T^{\mu 0}\right )d^3\vect {r} \end{equation*}

назвемо моментом імпульсу поля2. Враховуючи (9.11), дістанемо:

\(\seteqnumber{0}{9.}{13}\)

\begin{equation} \label {eq:angular_conservation} \frac {d\mathcal {M}^{\mu \nu }}{dt} + \oint \limits _{\partial \Omega _3}d\sigma _i\!\left (x^{\mu }T^{\nu i} - x^{\nu }T^{\mu i}\right ) + \frac {d}{dt}\int \limits _{\Omega _3}M^{\mu \nu }\,dV = 0. \end{equation}

Це співвідношення виражає збереження 4-моменту імпульсу, причому \((x^{\mu }T^{\nu 0}-x^{\nu }T^{\mu 0})\) дає густину цієї величини, а другий доданок в (9.14) — її потік через \(\partial \Omega _3\). При просторових значеннях індексів \(\mu \), \(\nu \) це співвідношення подає закон збереження компонент звичайного моменту імпульсу.

2 Відповідно, підінтегральний вираз — тензор густини моменту імпульсу.

  • 9.4. Обчислити згортку \(T^{\mu \nu }T_{\mu \nu }\) та виразити її через інваріанти \(\mathcal {I}_1\) (7.5) та \(\mathcal {I}_2\) (7.6) і показати, що

    \(\seteqnumber{0}{9.}{14}\)

    \begin{equation*} T^{\mu \nu }T_{\mu \nu } = \frac {4\mathcal {I}_1^2 + \mathcal {I}_2^2}{16(4\pi )^2}. \end{equation*}

    \(\seteqnumber{0}{9.}{14}\)

    \begin{equation*} T^{00} = w = \frac {\Efield ^2 + \Bfield ^2}{8\pi }, \qquad T^{0i} = \frac {\Pi ^i}{c} = \frac {[\Efield \times \Bfield ]^i}{4\pi c}, \end{equation*}

    показати, що

    \(\seteqnumber{0}{9.}{14}\)

    \begin{equation*} w^2 - \frac {\vect {\Pi }^2}{c^2} = \frac {1}{2}\,T^{\mu \nu }T_{\mu \nu } = \frac {4\mathcal {I}_1^2 + \mathcal {I}_2^2}{32(4\pi )^2}. \end{equation*}

    За яких умов на поле \(w^2 - \vect {\Pi }^2/c^2 = 0\)?
